Bilingual (EN / عربي). Every user is decomposed to the same depth: app → user → service → function → Input/Output. Each function is prefixed with its SRS requirement ID (e.g. 4.2.1) so the map and the SRS are one connected model. Colour = build status.

Scenarios · سيناريوهات

Each scenario: the situation in the centre, every user as a branch, each step as a function you can open to its In / Out. Covers the journey plus patients who can't see / hear / speak, the elderly, and other-language patients.
