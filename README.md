# A.B.C.D.E — Patient App Prototype

Clickable UI mockup of the patient mobile app for the A.B.C.D.E healthcare system, designed for Alamein Model Hospital.

A single-patient walkthrough (cardiac catheterization case) covering the full visit journey, with patient-centered care principles built into every stage.

## Files

| File | What it is |
|------|-----------|
| `index.html` | Page structure and content |
| `styles.css` | All visual styling |
| `app.js` | All interactivity (navigation, modals, ratings, alerts) |

## Run locally

Open `index.html` in any modern browser. No build step, no dependencies.

## Deploy on GitHub Pages

1. Push this folder to a public GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch** → **main** → **/ (root)**.
4. Save. Your live link appears within 1–2 minutes:
   `https://<username>.github.io/<repository>/`

## Screens included

- 4-slide intro about Alamein Model Hospital
- Login (normal · QR code · guest mode)
- Home, with vitals, status, quick actions, and a notifications bell
- Care Journey with rateable stages
- Healthcare Advisor (AI chat)
- Care & Medication, Appointments, and Reports (health + financial)
- Family Access with QR-based and manual member adding
- Alerts (medication reminders, rate prompts, updates) — all clickable
- Learn & Relax (education videos + entertainment)

## Note

This is a clickable mockup with illustrative data. No live backend, no real authentication, no real camera, no real AI.
